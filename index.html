How to Install PaperMC Server

Follow these steps to run a Minecraft server on your local PC:

  1. Download and install Java 21 on your computer
  2. Download paper from the official website
  3. Create a new folder and place the paper.jar file inside it.
  4. Create a text file named run.bat and add this command: java -jar paper.jar
  5. Run run.bat once, open eula.txt, and change it to eula=true
  6. Run run.bat again and wait until the world generation is finished

Run Script Example (run.bat)

Create a batch file with the following startup flags:

            java -Xms2G -Xmx4G -jar paper.jar nogui
            pause
